# Driver/Nanny app feature stubs

Feature-first folders to be built per the roadmap:

- `shift/` — shift check-in (Phase 1) → source of admin Shift Readiness
- `route/` — ordered stop list + turn-by-turn handoff to Google Maps (Phase 4)
- `roster/` — mark student boarded/absent per stop (Phase 4)
- `trip/` — trip start/complete + GPS foreground-service streaming (Phase 4)
- `incidents/` — report breakdown / off-route (Phase 5) → Action Required
